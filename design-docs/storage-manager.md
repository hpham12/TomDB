# Storage Manager

## Requirements
1. Storage manager supports fetching a Page from disk, given a `pageId`
2. Storage manager supports persisting new pages/changes to existing pages
3. Storage manager supports deleting a page and reclaiming a slot in the page
4. Storage manager supports flushing changes to synchronize data with the storage device
5. Storage manager supports constructing pages from an existing database file on start up
6. Storage manager supports extending the database file to allow for additional pages
